```text
.

│   ├── api/                       # Конфігурація Axios та запити до API

│   │   ├── auth/                  # Компоненти авторизації та покрокових форм

│   ├── routes/                    # Маршрутизація та сторінки проєкту
│   │   ├── layouts/               # Макети для захисту та групування роутів
│   │   └── *.tsx                  # Сторінки проєкту
│   ├── types/                     # Глобальні типи та інтерфейси TypeScript
│   │   └── index.ts
│   ├── app.css                    # Глобальні стилі
│   ├── root.tsx                   # Кореневий компонент додатка
│   └── routes.ts                  # Конфігурація маршрутизатора
│
├── .github/                       # Шаблони PR, Issue та CI/CD workflows
├── .husky/                        # Git hooks для автоматичних перевірок
├── public/                        # Статичні файли: іконки, шрифти, зображення
├── .eslintrc.json                 # Конфігурація ESLint
├── .prettierrc                    # Конфігурація Prettier
├── CONTRIBUTING.md                # Правила та рекомендації для контриб'юторів
├── package.json                   # Залежності та npm-скрипти
└── README.md                      # Основна документація проєкту
```

## 🚀 Швидкий старт

### Передумови

Перед початком роботи переконайтеся, що у вас встановлено:

- **Node.js** — версія `18.x` або вище; [Як встановити Node (**Вкрай** рекомендовано використовувати nvm/або інший node version manager)](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)
- **yarn** — пакетний менеджер. Yarn Berry (v4); [Як встановити yarn berry (Використовувати частину `yarn berry` гайду)](https://dev.to/arshak_grigoryan/yarn-classic-vs-yarn-berry-installation-guide-3oob)

### 1. Клонуйте репозиторій

```bash
git clone https://github.com/Delivery-Leleka/leleka-frontend

cd leleka-frontend
```

### 2. Встановіть залежності

```bash
yarn
```

Або:

```bash
yarn install
```

(Роблять однакову річ)

Після встановлення залежностей заповніть необхідні змінні середовища та ключі, якщо вони потрібні для роботи проєкту.

### 3. Запустіть проєкт

Для запуску локального сервера розробки виконайте:

```bash
yarn dev
```

Після запуску додаток буде доступний за адресою, яка відображена в терміналі

> ℹ️ Порт може відрізнятися. Актуальну адресу буде вказано в консолі після запуску.

## 🛠️ Корисні команди

Усі основні скрипти проєкту виконуються через `yarn <команда>`.

| Команда             | Опис                                    |
| ------------------- | --------------------------------------- |
| `yarn dev`      | Запуск проєкту в режимі розробки з HMR  |
| `yarn build`    | Збірка проєкту для продакшну            |
| `yarn preview`  | Локальний перегляд продакшн-збірки      |
| `yarn lint`     | Перевірка коду за допомогою ESLint      |
| `yarn lint:fix` | Автоматичне виправлення помилок ESLint  |
| `yarn format`   | Форматування коду за допомогою Prettier |

## 🐶 Husky та автоматизація

У проєкті використовується **Husky** разом із **lint-staged** для підтримки чистоти коду та єдиного стилю оформлення.

### Як це працює?

Під час виконання:

```bash
git commit
```

Husky автоматично запускає `pre-commit` hook, який:

1. 🔍 Перевіряє змінені файли (`staged files`).
2. 🧹 Запускає **ESLint** для перевірки коду.
3. ✨ Запускає **Prettier** для автоматичного форматування.

### ⚠️ Важливо

Якщо в коді є помилки, які ESLint не може виправити автоматично, **коміт буде відхилено**.

У такому випадку:

1. Виправте помилки, зазначені ESLint.
2. Перевірте форматування.
3. Повторіть `git commit`.
